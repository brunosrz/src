# Architecture Decision Records

ADRs registram decisões que influenciam a evolução de mais de um estudo ou a operação do
repositório. Não crie um ADR para uma alteração local e óbvia.

Copie o [modelo](template.md), use numeração sequencial e mantenha o estado `proposed`, `accepted`,
`superseded` ou `rejected`. Um ADR explica contexto, alternativas, decisão e consequências; não
substitui a documentação de uso.
